## 1. 各类数据结构的类图

## 2. 核心数据结构详解

### 2.1 Token（词法单元）

**所在文件**：`src/lexer/Token.java`

| 字段 | 类型 | 说明 |
|------|------|------|
| `kind` | `String` | Token 类别：KW / Ident / Num / Op / Delim / BadToken |
| `value` | `String` | Token 的词素值（如 "const", "a", "10", ":="） |
| `lineno` | `int` | 所在源代码行号（用于错误定位） |

**设计意图**：采用简单的数据类，作为词法分析器输出和语法分析器输入的中间表示。kind 用于语法分析的 lookahead 决策，lineno 用于错误报告。

### 2.2 LexerError（词法错误）

**所在文件**：`src/lexer/LexerError.java`

| 字段 | 类型 | 说明 |
|------|------|------|
| `msg` | `String` | 错误消息，格式为 `"错误类型,详情"`（如 `"BadToken,2a"`） |
| `lineno` | `int` | 出错行号 |

**错误类型表**：

| msg 格式 | 含义 |
|----------|------|
| `BadToken,xxx` | 非法单词（如数字开头的 `2a`） |
| `LongIdent,xxx` | 标识符超长（>8 字符） |
| `NumOverflow,xxx` | 数字越界（>8 位） |
| `BadChar,x` | 非法字符（如 `@` `&` `!`） |

### 2.3 SemanticError（语义错误）

**所在文件**：`src/parser/SemanticError.java`

| 字段 | 类型 | 说明 |
|------|------|------|
| `msg` | `String` | 错误描述（如 `"Undecl x"`, `"Dup var a"`） |
| `lineno` | `int` | 出错行号 |

### 2.4 Quadruple（四元式）

**所在文件**：`src/quadruple/Quadruple.java`

| 字段 | 类型 | 说明 |
|------|------|------|
| `op` | `String` | 操作码（如 `+`, `:=`, `j`, `read`, `call`） |
| `arg1` | `String` | 第一操作数 |
| `arg2` | `String` | 第二操作数 |
| `result` | `String` | 结果（临时变量或目标地址） |

**输出格式**：`(op, arg1, arg2, result)`

**四元式分类**：

| 类别 | 示例 | 说明 |
|------|------|------|
| 运算 | `(+, b, a, T2)` | T2 = b + a |
| 赋值 | `(:=, T2, _, c)` | c = T2 |
| 常量声明 | `(=, 10, _, a)` | a = 10 |
| 跳转 | `(j=, T1, 0, 12)` | if T1 == 0 goto (12) |
| 无条件跳转 | `(j, _, _, 3)` | goto (3) |
| 输入/输出 | `(read, b, _, _)` / `(write, T4, _, _)` | 读/写 |
| 过程 | `(call, p, _, _)` / `(procedure, p, _, _)` | 调用/声明 |
| 程序控制 | `(syss, _, _, _)` / `(syse, _, _, _)` | 程序开始/结束 |

### 2.5 QuadrupleManager（四元式管理器）

**所在文件**：`src/quadruple/QuadrupleManager.java`

| 字段 | 类型 | 说明 |
|------|------|------|
| `quads` | `List<Quadruple>` | 四元式列表 |
| `tempCount` | `int` | 临时变量计数器（T1, T2, ...） |
| `labelCount` | `int` | 标签计数器（$1, $2, ...） |
| `pending` | `Map<String, List<Integer>>` | 待回填的跳转地址映射 |

**核心方法**：

| 方法 | 作用 |
|------|------|
| `emit(op, a1, a2, r)` | 发射一条四元式，返回编号 |
| `newTemp()` | 创建新临时变量（返回 `T1`, `T2`...） |
| `newLabel()` | 创建新标签（返回 `$1`, `$2`...） |
| `emitWP(op, a1, a2, label)` | 发射待回填的跳转四元式 |
| `patch(label)` | 回填标签对应的所有跳转目标 |
| `toStr()` | 将四元式列表格式化为字符串 |

### 2.6 Symbol（符号条目）

**所在文件**：`src/symbol/Symbol.java`

| 字段 | 类型 | 说明 |
|------|------|------|
| `name` | `String` | 符号名称（如 `a`, `b`, `p`） |
| `kind` | `String` | 符号种类：`const` / `var` / `procedure` |
| `value` | `String` | 值（常量有具体值，变量/过程默认 `"0"`） |
| `level` | `int` | 所在作用域层级（0=全局） |
| `addr` | `int` | 地址（当前未使用，预留） |

### 2.7 SymbolTable（符号表管理器）

**所在文件**：`src/symbol/SymbolTable.java`

| 字段 | 类型 | 说明 |
|------|------|------|
| `scopes` | `List<Map<String, Symbol>>` | 作用域栈（每个作用域一个 HashMap） |
| `all` | `List<Symbol>` | 所有符号的扁平列表（用于输出） |

**核心方法**：

| 方法 | 作用 |
|------|------|
| `enterScope()` | 进入新作用域（push 新 HashMap） |
| `exitScope()` | 退出当前作用域（pop） |
| `add(name, kind, value)` | 在当前作用域添加符号，重复返回 false |
| `add(name, kind)` | 简化版，value 默认 "0" |
| `lookup(name)` | 从内向外逐层查找符号 |
| `level()` | 返回当前作用域层级 |

## 3. 数据结构之间的关联

```
                        Main
                      /   |   \
                     /    |    \
                    /     |     \
              Lexer     LR1Parser  输出显示
               |         /    \
               |        /      \
            Token ←───┘        │
              |                │
              |         QuadrupleManager ──→ Quadruple[]
              |                │
              |         SymbolTable ──→ Symbol[]
              |
         LexerError[]    SemanticError[]
```

1. **Lexer** 读取源代码生成 `Token[]` 和 `LexerError[]`
2. **LR1Parser** 接收 `Token[]`，递归下降解析过程中：
   - 使用 **SymbolTable** 记录和查询符号
   - 使用 **QuadrupleManager** 生成 **Quadruple[]**
   - 发现语义错误记录为 **SemanticError[]**
3. **Main** 收集所有输出并格式化显示
