## 1. 总体架构流程

```mermaid
flowchart TD
    Start([开始]) --> Read[读取源代码 .pl0 文件]
    Read --> Lexer[词法分析 Lexer.tokenize]
    Lexer --> TokenStream[Token 流 + 词法错误]
    TokenStream --> Parser[语法+语义分析 LR1Parser.parse]
    
    subgraph Parser[语法+语义分析 LR1Parser.parse]
        direction TB
        PD[递归下降解析] --> SA[语法制导翻译 S-Translation]
        SA --> QM[发射四元式 QuadrupleManager.emit]
        SA --> ST[管理符号表 SymbolTable]
    end
    
    Parser --> Output[输出结果]
    Output --> Quads[四元式序列]
    Output --> SymTable[符号表]
    Output --> Errors[错误列表]
    Quads --> End([结束])
    SymTable --> End
    Errors --> End

    style Lexer fill:#4CAF50,color:#fff
    style Parser fill:#2196F3,color:#fff
    style QM fill:#FF9800,color:#fff
    style ST fill:#9C27B0,color:#fff
```

## 2. 词法分析流程图

> 分两段展示：主循环 和 字符分类

### 2.1 主循环 + 注释处理

```mermaid
flowchart TD
    Start([tokenize 入口]) --> Lines[按换行符分割为行数组]
    Lines --> Loop{遍历每一行}
    
    Loop --> InBlock{处于多行注释中?}
    InBlock -->|是| FindEnd[查找行内 */]
    FindEnd -->|找到| Skip[跳过到 */ 后]
    Skip --> ColLoop
    FindEnd -->|未找到| ContinueLoop[跳过本行]
    ContinueLoop --> Loop
    
    InBlock -->|否| ColLoop{遍历每个字符}
    ColLoop -->|本行处理完| Loop
    Loop -->|全部行处理完| Return([返回 Token 列表])

    style Start fill:#4CAF50,color:#fff
    style Return fill:#4CAF50,color:#fff
```

### 2.2 字符分类识别

```mermaid
flowchart TD
    ColLoop[依次取字符 ch] --> IsWS{空白字符?}
    IsWS -->|是| NextWS[col++]
    NextWS --> ColLoop
    
    IsWS -->|否| IsLineComment{// 注释?}
    IsLineComment -->|是| SkipLine[跳过整行]
    SkipLine --> ColLoop
    
    IsLineComment -->|否| IsBlockComment{/* 注释?}
    IsBlockComment -->|是| FindBlockEnd[查找行内 */]
    FindBlockEnd -->|找到| AfterBlock[跳到 */ 后]
    AfterBlock --> ColLoop
    FindBlockEnd -->|未找到| SetInBlock[标记 inBlock]
    SetInBlock --> ColLoop
    
    IsBlockComment -->|否| Is2Op{双字符运算符?}
    Is2Op -->|是| Emit2Op[生成 Op Token]
    Emit2Op --> ColLoop
    
    Is2Op -->|否| Is1Op{单字符运算符?}
    Is1Op -->|是| Emit1Op[生成 Op Token]
    Emit1Op --> ColLoop
    
    Is1Op -->|否| IsDelim{界符?}
    IsDelim -->|是| EmitDelim[生成 Delim Token]
    EmitDelim --> ColLoop
    
    IsDelim -->|否| IsLetter{字母或下划线?}
    IsLetter -->|是| ReadWord[读完整单词]
    ReadWord --> IsKW{是关键字?}
    IsKW -->|是| EmitKW[生成 KW Token]
    EmitKW --> ColLoop
    IsKW -->|否| CheckLen{长度>8?}
    CheckLen -->|是| ErrLong[报 LongIdent 错误]
    ErrLong --> EmitIdent
    CheckLen -->|否| EmitIdent[生成 Ident Token]
    EmitIdent --> ColLoop
    
    IsLetter -->|否| IsDigit{数字?}
    IsDigit -->|是| ReadNum[读入数字]
    ReadNum --> NumLetter{后跟字母?}
    NumLetter -->|是| EmitBad[生成 BadToken]
    EmitBad --> ColLoop
    NumLetter -->|否| NumLen{位数>8?}
    NumLen -->|是| ErrOverflow[报 NumOverflow 错误]
    NumLen -->|否| EmitNum[生成 Num Token]
    ErrOverflow --> EmitNum
    EmitNum --> ColLoop
    
    IsDigit -->|否| ErrChar[报 BadChar 错误]
    ErrChar --> ColLoop

    style ErrChar fill:#f44336,color:#fff
    style ErrLong fill:#f44336,color:#fff
    style ErrOverflow fill:#f44336,color:#fff
```

## 3. 递归下降语法分析流程图

### 3.1 总体解析树

```mermaid
flowchart TD
    P([parse 入口]) --> PB[parseBlock]
    
    PB --> PC[parseConst 常量声明]
    PB --> PV[parseVar 变量声明]
    PB --> PP[parseProc 过程声明]
    PB --> PS[parseStmt 语句分发]
    
    PS -->|id| PA[parseAssign 赋值]
    PS -->|read| PR[parseRead 读]
    PS -->|write| PW[parseWrite 写]
    PS -->|call| PCALL[parseCall 调用]
    PS -->|begin| PCOMP[parseStmtList 复合语句]
    PS -->|if| PIF[parseIf 条件]
    PS -->|while| PWHILE[parseWhile 循环]
    PS -->|odd| PCOND[parseCond 条件]

    PA --> Expr[parseExpr 表达式]
    Expr --> ET[parseETail 加减]
    ET --> T[parseTTail 乘除]
    T --> F[parseFact 因子]
    F --> Fid[标识符 查符号表]
    F --> Fnum[数字 直接返回]
    F --> Fparen[子表达式 递归]

    style P fill:#2196F3,color:#fff
    style PS fill:#FF9800,color:#fff
    style PIF fill:#9C27B0,color:#fff
    style PWHILE fill:#9C27B0,color:#fff
```

### 3.2 表达式解析流程（消除左递归）

```mermaid
flowchart TD
    subgraph Expr[parseExpr 表达式解析]
        direction LR
        T1[parseTerm 得到 l] --> E1{peek 是 + 或 -?}
        E1 -->|是| N1[next 消费运算符]
        N1 --> T2[parseTerm 得到 rr]
        T2 --> EM1[newTemp 得到 r  emit +- l rr r]
        EM1 --> ER1[递归 parseETail r]
        E1 -->|否| R1[返回 l]
        ER1 --> E1
    end
    
    subgraph Term[parseTerm 项解析]
        direction LR
        FT[parseFact 得到 l] --> T1T{peek 是 * 或 /?}
        T1T -->|是| N2[next 消费运算符]
        N2 --> F2[parseFact 得到 rr]
        F2 --> EM2[newTemp 得到 r  emit */ l rr r]
        EM2 --> TR[递归 parseTTail r]
        T1T -->|否| R2[返回 l]
        TR --> T1T
    end
    
    Expr --> Term

    style Expr fill:#E3F2FD
    style Term fill:#F3E5F5
```

### 3.3 条件语句 if-then-else 流程

```mermaid
flowchart TD
    StartIf([parseIf 入口]) --> NL[newLabel fl 和 el]
    NL --> Cond[parseCond 得到 cp]
    Cond --> CT{匹配 THEN?}
    CT -->|否| ErrThen[报错 Expect THEN]
    CT -->|是| WP1[emitWP j= cp 0 fl]
    WP1 --> TS[parseStmt then 子句]
    TS --> WP2[emitWP j _ _ el]
    WP2 --> PF[patch fl 回填]
    PF --> CE{匹配 ELSE?}
    CE -->|是| ES[parseStmt else 子句]
    CE -->|否| PE[patch el 回填]
    ES --> PE
    PE --> EndIf([返回])

    style StartIf fill:#4CAF50,color:#fff
    style EndIf fill:#4CAF50,color:#fff
    style PF fill:#FF9800,color:#fff
    style PE fill:#FF9800,color:#fff
```

### 3.4 循环语句 while-do 流程

```mermaid
flowchart TD
    StartWhile([parseWhile 入口]) --> NL[newLabel ls 和 ex]
    NL --> PLS[loopStart = patch ls]
    PLS --> Cond[parseCond 得到 cp]
    Cond --> CD{匹配 DO?}
    CD -->|否| ErrDo[报错 Expect DO]
    CD -->|是| WP[emitWP j= cp 0 ex]
    WP --> Body[parseStmt 循环体]
    Body --> JB[emit j _ _ loopStart 跳回条件]
    JB --> PEX[patch ex 回填出口]
    PEX --> EndWhile([返回])

    style StartWhile fill:#4CAF50,color:#fff
    style EndWhile fill:#4CAF50,color:#fff
    style JB fill:#FF9800,color:#fff
    style PEX fill:#FF9800,color:#fff
```

## 4. 四元式回填流程图

```mermaid
flowchart TD
    subgraph emitWP[emitWP 阶段 延迟绑定]
        direction TB
        S1[遇到控制流 if / while] --> S2[newLabel 得到 $N]
        S2 --> S3[emit op a1 a2 $N result 暂填标签名]
        S3 --> S4[pending[$N].add(idx) 记录待回填编号]
    end
    
    subgraph patch[patch 阶段 地址回填]
        direction TB
        P1[确定目标 pos = quadCount + 1] --> P2[从 pending 取出 label 对应的 idx]
        P2 --> P3{FOR 每个 idx}
        P3 -->|idx = 5| F5[quads[4].result = pos]
        P3 -->|idx = 12| F12[quads[11].result = pos]
        F5 --> P3
        F12 --> P3
        P3 -->|全部完成| P4[pending.remove(label)]
    end
    
    emitWP -.->|延迟绑定| patch

    style emitWP fill:#E3F2FD
    style patch fill:#F3E5F5
    style F5 fill:#FF9800,color:#fff
    style F12 fill:#FF9800,color:#fff
```

### 回填示例：if-then-else

```
源代码:  if a <= 10 then c := b + a else c := 0

四元式生成过程:
(1) syss
(2) <= a 10 T1
(3) j= T1 0 $1       <- emitWP: 条件为假时跳 $1
(4) + b a T2
(5) := T2 _ c
(6) j _ _ $2          <- emitWP: then 结束后跳 $2
    -> patch($1): 将 $1 回填为 7  <- $1 = 当前位置
(7) = 0 _ c
    -> patch($2): 将 $2 回填为 8  <- $2 = 当前位置
(8) syse
```

## 5. 符号表管理流程图

```mermaid
flowchart TD
    subgraph Scope[作用域管理]
        direction LR
        EN[enterScope push 新 HashMap] --> Use[执行 parseBlock]
        Use --> EX[exitScope pop 当前 HashMap]
    end
    
    subgraph Add[符号添加]
        A[add name kind value] --> CK{当前作用域已有同名符号?}
        CK -->|有| RF[返回 false 重复声明]
        CK -->|无| AS[创建 Symbol 加入当前作用域]
        AS --> RT[返回 true]
    end
    
    subgraph Lookup[符号查找]
        L[lookup name] --> LS{FOR i 从 scope深度-1 到 0}
        LS -->|当前层| FD{scopes[i] 包含 name?}
        FD -->|是| RTN[返回 Symbol]
        FD -->|否| LS
        LS -->|全部查完| RNULL[返回 null 未声明]
    end
    
    EN --> Add
    Add --> Lookup

    style EN fill:#4CAF50,color:#fff
    style EX fill:#f44336,color:#fff
    style RF fill:#f44336,color:#fff
    style RNULL fill:#f44336,color:#fff
```

## 6. 错误处理流程

```mermaid
flowchart LR
    subgraph LexErr[词法错误检测]
        L1[非法字符 @ & !] --> LO1[报 BadChar]
        L2[数字+字母 如 2a] --> LO2[报 BadToken]
        L3[标识符长度 > 8] --> LO3[报 LongIdent]
        L4[数字位数 > 8] --> LO4[报 NumOverflow]
    end
    
    subgraph SemErr[语义错误检测]
        S1[st.lookup = null] --> SO1[报 Undecl]
        S2[st.add = false] --> SO2[报 DupDecl]
        S3[给常量赋值] --> SO3[报 const not var]
        S4[调用非过程] --> SO4[报 not proc]
    end
    
    subgraph Recover[错误恢复策略]
        R1[记录错误] --> R2[用占位值 _ 继续]
        R2 --> R3[不中断解析]
        R3 --> R4[继续发现更多错误]
    end
    
    LexErr --> Recover
    SemErr --> Recover

    style L1 fill:#f44336,color:#fff
    style L2 fill:#f44336,color:#fff
    style L3 fill:#f44336,color:#fff
    style L4 fill:#f44336,color:#fff
    style S1 fill:#f44336,color:#fff
    style S2 fill:#f44336,color:#fff
    style S3 fill:#f44336,color:#fff
    style S4 fill:#f44336,color:#fff
    style Recover fill:#FF9800,color:#fff
```

## 7. 主控流程

```mermaid
flowchart TD
    Main([Main.main]) --> Args{args 长度?}
    
    Args -->|0| Examples[runExamples 运行内置示例]
    Args -->|其他| File{args[0] 是目录?}
    
    File -->|是| Batch[batch 遍历目录下所有 .pl0]
    File -->|否| Single[file 分析单个 .pl0 文件]
    
    Examples --> Ex1[示例1: 正确程序]
    Examples --> Ex2[示例2: 语义错误]
    
    Single --> Read[ReadFile 得到 code]
    Read --> Lex[new Lexer 得到 tokens]
    Lex --> Par[new LR1Parser 得到 quads + symtbl + errs]
    Par --> Output[输出结果]
    
    Batch --> Files[遍历 .pl0 文件]
    Files --> Single

    style Main fill:#2196F3,color:#fff
    style Examples fill:#4CAF50,color:#fff
    style Single fill:#FF9800,color:#fff
    style Batch fill:#9C27B0,color:#fff
---
