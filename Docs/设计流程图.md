## 1. 总体架构流程

```mermaid
flowchart TD
    Start([开始]) --> Read[读取源代码 .pl0 文件]
    Read --> Lexer[词法分析 Lexer.tokenize]
    Lexer --> TokenStream[Token 流 + 词法错误]
    TokenStream --> Parser[语法+语义分析 LR1Parser.parse]
    
    subgraph Parser[语法+语义分析 LR1Parser.parse]
        direction TB
        PD[递归下降解析] --> SA[语法制导翻译 S-Translation]
        SA --> QM[发射四元式 QuadrupleManager.emit]
        SA --> ST[管理符号表 SymbolTable]
    end
    
    Parser --> Output[输出结果]
    Output --> Quads[四元式序列]
    Output --> SymTable[符号表]
    Output --> Errors[错误列表]
    Quads --> End([结束])
    SymTable --> End
    Errors --> End

    style Lexer fill:#4CAF50,color:#fff
    style Parser fill:#2196F3,color:#fff
    style QM fill:#FF9800,color:#fff
    style ST fill:#9C27B0,color:#fff
```

## 2. 词法分析流程图

> 分两段展示：主循环 和 字符分类

### 2.1 主循环 + 注释处理

```mermaid
flowchart TD
    Start([tokenize 入口]) --> Lines[按换行符分割为行数组]
    Lines --> Loop{遍历每一行}
    
    Loop -->|每行| InBlock{处于多行注释中?}
    InBlock -->|是| FindEnd[查找行内 */]
    FindEnd -->|找到| Skip[跳过到 */ 后] --> ColLoop
    FindEnd -->|未找到| ContinueLoop[跳过本行] --> Loop
    
    InBlock -->|否| ColLoop{遍历每个字符}

    ColLoop -->|字符处理完毕| Loop
    Loop -->|所有行处理完| Return([返回 Token 列表])

    style Start fill:#4CAF50,color:#fff
    style Return fill:#4CAF50,color:#fff
```

### 2.2 字符分类识别

```mermaid
flowchart TD
    ColLoop[依次取字符 ch] --> IsWS{空白字符?}
    IsWS -->|是| NextWS[col++] --> ColLoop
    
    IsWS -->|否| IsLineComment{// 注释?}
    IsLineComment -->|是| SkipLine[跳过整行] --> Loop
    
    IsLineComment -->|否| IsBlockComment{/* 注释?}
    IsBlockComment -->|是| FindBlockEnd[查找行内 */]
    FindBlockEnd -->|找到| AfterBlock[跳到 */ 后] --> ColLoop
    FindBlockEnd -->|未找到| SetInBlock[标记 inBlock] --> Loop
    
    IsBlockComment -->|否| Is2Op{双字符运算符? := <= >=}
    Is2Op -->|是| Emit2Op[生成 Op Token] --> ColLoop
    
    Is2Op -->|否| Is1Op{单字符运算符? + - * / = # < >}
    Is1Op -->|是| Emit1Op[生成 Op Token] --> ColLoop
    
    Is1Op -->|否| IsDelim{界符? ( ) ; , .}
    IsDelim -->|是| EmitDelim[生成 Delim Token] --> ColLoop
    
    IsDelim -->|否| IsLetter{字母或下划线?}
    IsLetter -->|是| ReadWord[读完整单词]
    ReadWord --> IsKW{是关键字?}
    IsKW -->|是| EmitKW[生成 KW Token] --> ColLoop
    IsKW -->|否| CheckLen{长度>8?}
    CheckLen -->|是| ErrLong[报 LongIdent 错误]
    CheckLen -->|否| EmitIdent[生成 Ident Token] --> ColLoop
    ErrLong --> EmitIdent
    
    IsLetter -->|否| IsDigit{数字?}
    IsDigit -->|是| ReadNum[读入数字]
    ReadNum --> NumLetter{后跟字母? 如 2a}
    NumLetter -->|是| EmitBad[生成 BadToken] --> ColLoop
    NumLetter -->|否| NumLen{位数>8?}
    NumLen -->|是| ErrOverflow[报 NumOverflow 错误]
    NumLen -->|否| EmitNum[生成 Num Token] --> ColLoop
    ErrOverflow --> EmitNum
    
    IsDigit -->|否| ErrChar[报 BadChar 错误] --> ColLoop

    style ErrChar fill:#f44336,color:#fff
    style ErrLong fill:#f44336,color:#fff
    style ErrOverflow fill:#f44336,color:#fff
```

## 3. 递归下降语法分析流程图

### 3.1 总体解析树

```mermaid
flowchart TD

    PB --> PC[parseConst<br/>常量声明]
    PB --> PV[parseVar<br/>变量声明]

    PB --> PS[parseStmt<br/>语句分发]
    
    PS --> PA[parseAssign 赋值]
    PS --> PR[parseRead 读]
    PS --> PW[parseWrite 写]

    Expr --> ET[parseETail +/-]
    ET --> T[parseTTail *//]
    T --> F[parseFact 因子]
    F --> Fid[标识符 → st.lookup]
    F --> Fnum[数字 → 直接返回]
    F --> Fparen[子表达式 ( ]
```

### 3.2 表达式解析流程（消除左递归）

```mermaid
flowchart TD
    subgraph parseExpr[parseExpr 表达式解析]
        direction LR
        T1[parseTerm → l] --> ET1{peek 是 + 或 -?}
        ET1 -->|是| Next1[next 消费运算符]
        Next1 --> T2[parseTerm → rr]
        T2 --> E1[newTemp → r  emit +- l rr r]
        E1 --> ET1R[递归 parseETail r]
        ET1 -->|否| Ret1[返回 l]
        ET1R --> ET1
    end
    
    subgraph parseTerm[parseTerm 项解析]
        direction LR
        F1[parseFact → l] --> TT1{peek 是 * 或 /?}
        TT1 -->|是| Next2[next 消费运算符]
        Next2 --> F2[parseFact → rr]
        F2 --> E2[newTemp → r  emit */ l rr r]
        E2 --> TT1R[递归 parseTTail r]
        TT1 -->|否| Ret2[返回 l]
        TT1R --> TT1
    end
    
    parseExpr --> parseTerm

    style parseExpr fill:#E3F2FD
    style parseTerm fill:#F3E5F5
```

### 3.3 条件语句 if-then-else 流程

```mermaid
flowchart TD
    StartIf([parseIf 入口]) --> NewLabel[newLabel → fl 和 el]
    NewLabel --> Cond[parseCond → cp]
    Cond --> CheckThen{匹配 THEN?}
    CheckThen -->|否| ErrThen[报错 Expect THEN]
    CheckThen -->|是| EmitWP1[emitWP j= cp 0 fl]
    EmitWP1 --> ThenStmt[parseStmt ← then 子句]
    ThenStmt --> EmitWP2[emitWP j _ _ el]
    EmitWP2 --> PatchFL[patch fl 回填到当前位置]
    PatchFL --> CheckElse{匹配 ELSE?}
    CheckElse -->|是| ElseStmt[parseStmt ← else 子句]
    CheckElse -->|否| PatchEL[patch el 回填到当前位置]
    ElseStmt --> PatchEL
    PatchEL --> EndIf([返回])

    style StartIf fill:#4CAF50,color:#fff
    style EndIf fill:#4CAF50,color:#fff
    style PatchFL fill:#FF9800,color:#fff
    style PatchEL fill:#FF9800,color:#fff
```

### 3.4 循环语句 while-do 流程

```mermaid
flowchart TD
    StartWhile([parseWhile 入口]) --> NewLabel[newLabel → ls 和 ex]
    NewLabel --> PatchLS[loopStart = patch ls]
    PatchLS --> Cond[parseCond → cp]
    Cond --> CheckDo{匹配 DO?}
    CheckDo -->|否| ErrDo[报错 Expect DO]
    CheckDo -->|是| EmitWP[emitWP j= cp 0 ex]
    EmitWP --> Body[parseStmt ← 循环体]
    Body --> JumpBack[emit j _ _ loopStart]
    JumpBack --> PatchEx[patch ex 回填出口]
    PatchEx --> EndWhile([返回])

    style StartWhile fill:#4CAF50,color:#fff
    style EndWhile fill:#4CAF50,color:#fff
    style JumpBack fill:#FF9800,color:#fff
    style PatchEx fill:#FF9800,color:#fff
```

## 4. 四元式回填流程图

```mermaid
flowchart TD
    subgraph emitWP[emitWP 阶段 延迟绑定]
        direction TB
        WP1[遇到控制流语句 if / while] --> WP2[newLabel → $N]
        WP2 --> WP3[emit op a1 a2 $N  result暂填标签名]
        WP3 --> WP4[pending[$N].add(idx) 记录待回填编号]
    end
    
    subgraph patch[patch 阶段 地址回填]
        direction TB
        P1[确定目标位置 pos = quadCount + 1] --> P2[从 pending 取出 label 对应的 idx 列表]
        P2 --> P3{FOR 每个 idx}
        P3 -->|idx = 5| Fill5[quads[4].result = pos]
        P3 -->|idx = 12| Fill12[quads[11].result = pos]
        Fill5 --> P3
        Fill12 --> P3
        P3 -->|全部完成| P4[pending.remove(label)]
    end
    
    emitWP -.->|延迟绑定| patch

    style emitWP fill:#E3F2FD
    style patch fill:#F3E5F5
    style Fill5 fill:#FF9800,color:#fff
    style Fill12 fill:#FF9800,color:#fff
```

### 回填示例：if-then-else

```
源代码:  if a <= 10 then c := b + a else c := 0

四元式生成过程:
(1) syss
(2) <= a 10 T1
(3) j= T1 0 $1       ← emitWP: 条件为假时跳 $1
(4) + b a T2
(5) := T2 _ c
(6) j _ _ $2          ← emitWP: then 结束后跳 $2
    → patch($1): 将 $1 回填为 7  ← $1 = 当前位置
(7) = 0 _ c
    → patch($2): 将 $2 回填为 8  ← $2 = 当前位置
(8) syse
```

## 5. 符号表管理流程图

```mermaid
flowchart TD
    subgraph Scope[作用域管理]
        direction LR
        Enter[enterScope push 新 HashMap] --> Use[在作用域内 执行parseBlock]
        Use --> Exit[exitScope pop 当前 HashMap]
    end
    
    subgraph Add[符号添加]
        A[add name kind value] --> Check{当前作用域已有同名符号?}
        Check -->|有| RetFalse[返回 false 重复声明]
        Check -->|无| AddSym[创建 Symbol 加入当前作用域和全局列表]
        AddSym --> RetTrue[返回 true]
    end
    
    subgraph Lookup[符号查找]
        L[lookup name] --> LoopScope{FOR i = scope深度-1 DOWNTO 0}
        LoopScope -->|当前层| Find{scopes[i] 包含 name?}
        Find -->|是| Return[返回 Symbol]
        Find -->|否| LoopScope
        LoopScope -->|全部查完| RetNull[返回 null 未声明]
    end
    
    Enter --> Add
    Add --> Lookup

    style Enter fill:#4CAF50,color:#fff
    style Exit fill:#f44336,color:#fff
    style RetFalse fill:#f44336,color:#fff
    style RetNull fill:#f44336,color:#fff
```

## 6. 错误处理流程

```mermaid
flowchart LR
    subgraph LexErr[词法错误检测]
        L1[非法字符 @ & !] --> LOut[报 BadChar]
        L2[数字开头+字母 如 2a] --> LOut2[报 BadToken]
        L3[标识符长度 > 8] --> LOut3[报 LongIdent]
        L4[数字位数 > 8] --> LOut4[报 NumOverflow]
    end
    
    subgraph SemErr[语义错误检测]
        S1[st.lookup = null] --> SOut[报 Undecl]
        S2[st.add = false] --> SOut2[报 DupDecl]
        S3[给常量赋值] --> SOut3[报 const not var]
        S4[调用非过程] --> SOut4[报 not proc]
    end
    
    subgraph Recover[错误恢复策略]
        R1[记录错误] --> R2[用占位值 _ 继续]
        R2 --> R3[不中断解析]
        R3 --> R4[继续发现更多错误]
    end
    
    LexErr --> Recover
    SemErr --> Recover

    style L1 fill:#f44336,color:#fff
    style L2 fill:#f44336,color:#fff
    style L3 fill:#f44336,color:#fff
    style L4 fill:#f44336,color:#fff
    style S1 fill:#f44336,color:#fff
    style S2 fill:#f44336,color:#fff
    style S3 fill:#f44336,color:#fff
    style S4 fill:#f44336,color:#fff
    style Recover fill:#FF9800,color:#fff
```

## 7. 主控流程

```mermaid
flowchart TD
    Main([Main.main]) --> Args{args 长度?}
    
    Args -->|0| Examples[runExamples 运行内置示例]
    Args -->|>0| File{args[0] 是目录?}
    
    File -->|是| Batch[batch 遍历目录下所有 .pl0]
    File -->|否| Single[file 分析单个 .pl0 文件]
    
    Examples --> Ex1[示例1: 正确程序]
    Examples --> Ex2[示例2: 语义错误]
    
    Single --> Read[ReadFile  String code]
    Read --> Lex[new Lexer  tokenize  tokens]
    Lex --> Par[new LR1Parser  parse]
    Par --> Output[输出四元式 + 符号表 + 错误]
    
    Batch --> Files[遍历 .pl0 文件]
    Files --> Single

    style Main fill:#2196F3,color:#fff
    style Examples fill:#4CAF50,color:#fff
    style Single fill:#FF9800,color:#fff
    style Batch fill:#9C27B0,color:#fff
```
