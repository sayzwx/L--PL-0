## 1. 词法规则

### 1.1 关键字（保留字）

| 关键字 | 说明 |
|--------|------|
| `const` | 常量声明 |
| `var` | 变量声明 |
| `procedure` | 过程声明 |
| `call` | 过程调用 |
| `begin` | 复合语句开始 |
| `end` | 复合语句结束 |
| `if` | 条件语句 |
| `then` | 条件语句 |
| `else` | 条件语句（可选） |
| `while` | 循环语句 |
| `do` | 循环语句 |
| `read` | 读语句 |
| `write` | 写语句 |
| `odd` | 奇偶判断 |

### 1.2 运算符

| 类别 | 符号 |
|------|------|
| 赋值运算符 | `:=` |
| 关系运算符 | `=` `#` `<` `<=` `>` `>=` |
| 加减运算符 | `+` `-` |
| 乘除运算符 | `*` `/` |

### 1.3 界符

`(` `)` `;` `,` `.`

### 1.4 标识符

- 以字母或下划线开头，后跟字母、数字或下划线
- **长度限制**：不超过 8 个字符
- 正则：`[a-zA-Z_][a-zA-Z0-9_]{0,7}`

### 1.5 无符号整数

- 连续的数字序列
- **长度限制**：不超过 8 位
- 正则：`[0-9]{1,8}`

### 1.6 注释

| 类型 | 语法 | 说明 |
|------|------|------|
| 单行注释 | `//...` | 从 `//` 到行尾 |
| 多行注释 | `/* ... */` | 可跨行，不支持嵌套 |

### 1.7 非法字符

`@` `&` `!` 等不在上述集合中的字符均视为非法字符。

## 2. 语法规则（EBNF）

```
程序          ::= 块 .

块            ::= [常量声明部分] [变量声明部分] {过程声明部分} 语句

常量声明部分  ::= const 常量定义 {, 常量定义} ;
常量定义      ::= 标识符 = 无符号整数

变量声明部分  ::= var 标识符 {, 标识符} ;

过程声明部分  ::= procedure 标识符 ; 块 ;

语句          ::= 赋值语句
                 | 条件语句
                 | 循环语句
                 | 过程调用语句
                 | 读语句
                 | 写语句
                 | 复合语句
                 | 空语句

赋值语句      ::= 标识符 := 表达式 ;

条件语句      ::= if 条件 then 语句 [else 语句]

循环语句      ::= while 条件 do 语句

过程调用语句  ::= call 标识符 ;

读语句        ::= read ( 标识符 {, 标识符} ) ;

写语句        ::= write ( 表达式 {, 表达式} ) ;

复合语句      ::= begin 语句 {; 语句} end

空语句        ::= ε

条件          ::= 表达式 关系运算符 表达式
                 | odd 表达式

表达式        ::= [+|-] 项 { 加减运算符 项 }

项            ::= 因子 { 乘除运算符 因子 }

因子          ::= 标识符
                 | 无符号整数
                 | ( 表达式 )

加减运算符    ::= + | -

乘除运算符    ::= * | /

关系运算符    ::= = | # | < | <= | > | >=
```

## 3. 文法与代码的对应关系

| EBNF 产生式 | 对应解析方法 | 说明 |
|-------------|-------------|------|
| `程序 → 块 .` | `parse()` | 入口，调用 `parseBlock()` |
| `块 → ... 语句` | `parseBlock()` | 按序解析常量、变量、过程、语句 |
| `常量声明 → const ...` | `parseConst()` | 递归解析逗号分隔的常量定义 |
| `变量声明 → var ...` | `parseVar()` → `parseIds()` | 递归解析逗号分隔的变量名 |
| `过程声明 → procedure ...` | `parseProc()` | 进入新作用域后递归调用 `parseBlock()` |
| `语句 → ...` | `parseStmt()` | 根据 lookahead 分发到各语句解析方法 |
| `赋值语句 → id := expr` | `parseAssign()` | 查符号表，生成 `:=` 四元式 |
| `条件语句 → if ...` | `parseIf()` | 使用回填技术处理跳转 |
| `循环语句 → while ...` | `parseWhile()` | 使用回填技术处理循环跳转 |
| `表达式 → 项 ...` | `parseExpr()` → `parseETail()` | 左递归消除，尾递归解析 |
| `项 → 因子 ...` | `parseTerm()` → `parseTTail()` | 左递归消除，尾递归解析 |
| `因子 → id / num / (expr)` | `parseFact()` | 查符号表，处理括号表达式 |
